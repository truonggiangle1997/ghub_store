# GHub Store - Trung tâm Phân phối Ứng dụng

Kho lưu trữ phân phối và cập nhật ứng dụng tự động dành cho hệ sinh thái GHub.

> [!NOTE]
> **Giai đoạn Thử nghiệm (Public Beta):** Tất cả các ứng dụng hiện đang trong quá trình thử nghiệm và hoàn thiện tính năng. Chỉ tải trực tiếp **GHub**, các ứng dụng còn lại được cài đặt và cập nhật tự động bên trong GHub.
