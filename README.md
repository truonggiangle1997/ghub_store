# GHub Store - Trung tâm Phân phối Ứng dụng

Kho lưu trữ phân phối và cập nhật ứng dụng tự động dành cho hệ sinh thái GHub.

> [!NOTE]
> **Giai đoạn Thử nghiệm (Public Beta):** Tất cả các ứng dụng hiện đang trong quá trình thử nghiệm và hoàn thiện tính năng. Vui lòng cập nhật phiên bản mới nhất thường xuyên để có trải nghiệm tốt nhất.
